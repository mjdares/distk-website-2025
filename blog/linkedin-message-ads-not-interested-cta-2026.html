LinkedIn Message Ads in 2026: The Not Interested Button and the Rotation Default Change

Two quiet changes in mid-2026 altered how LinkedIn's inbox ad formats behave, without anyone editing a campaign. If your Message Ad or Conversation Ad numbers moved this year, start here.

What Changed in LinkedIn Message Ads and Conversation Ads in 2026?

Two changes in 2026 affect LinkedIn's inbox ad formats, and neither needed advertiser action, which is why many teams have not noticed. In June 2026 LinkedIn began automatically rendering a "Not Interested" call-to-action on Message Ads and Conversation Ads. In July 2026 it changed the default ad rotation for lead generation inbox campaigns from even rotation to optimised rotation. Both alter results without anyone touching a campaign.

Both changes sit inside what LinkedIn's API calls the SPONSORED_INMAILS campaign type, which covers Message Ads and Conversation Ads. They apply to ads created in Campaign Manager as well as through the API, so they matter to every advertiser using these formats, not only to developers.

Explain It Like I Am Five

The simple version

Imagine posting invitations through doors. LinkedIn has started printing a small "no thanks" button on every invitation, so people can say no instead of ignoring it. That changes how many yes and no answers you count. LinkedIn has also changed how it chooses which of your invitations to send: instead of taking turns fairly, it now sends more of whichever one seems to be working. That can be better, but if you were comparing invitations to learn which wording wins, the comparison is no longer fair unless you ask for turns again.

What Is the Not Interested CTA on LinkedIn Message Ads?

It is a button LinkedIn adds to your inbox ads automatically. The changelog for Message Ads says: "A Not Interested CTA is automatically rendered on Message Ads. The CTA is applied to new and existing ads at render time and is not exposed in the API. Use test sends to preview the behavior." The Conversation Ads note says the same CTA "is automatically rendered on the firstMessageContent for SponsoredConversations."

Three details from that wording matter in practice in 2026:

  • It applies to existing ads. Campaigns that were live before June now show the button too, because it is added "at render time".
  • You cannot remove it through the API. It "is not exposed in the API", so there is no field to switch it off.
  • Preview with a test send. LinkedIn's own instruction is to use test sends to see how it looks.

There is one API-visible trace. For Conversation Ads created in Campaign Manager, LinkedIn states that GET requests to /conversationAds/{sponsoredConversationURN}/sponsoredMessageContents "will now return a new NOT_INTERESTED value in the replyType field." Any integration that reads reply types and expects only the options it created should be checked so the new value does not break parsing.

Why Does a Not Interested Button Change Your Reporting in 2026?

Because it gives recipients a third outcome besides engaging and ignoring. LinkedIn's changelog does not describe how the button affects delivery or metrics, and this guide does not speculate about that. What can be said is practical: a visible decline option changes the mix of responses you see, so any comparison of Conversation Ad or Message Ad performance before and after June 2026 is not like for like.

  • Reset benchmarks from June 2026 for inbox formats rather than comparing with earlier periods.
  • Review the first message. With a decline option sitting next to it, the opening message has to earn the next step faster.
  • Check reply-type handling in any tool that reads Conversation Ad structures, because of the new NOT_INTERESTED value.

What Changed About Ad Rotation for Lead Generation InMail in 2026?

The default switched from even rotation to optimised rotation. LinkedIn's July 2026 note says: "Starting July 2026, the adCampaigns API will support, as the default, OPTIMIZED for creativeSelection in SPONSORED_INMAILS type campaigns (Message Ads and Conversation Ads) with the LEAD_GENERATION objective. Previously, this combination was rejected with a 400 validation error and forced to ROUND_ROBIN."

The consequence is spelled out directly: "If your integration creates or updates SPONSORED_INMAILS campaigns with the LEAD_GENERATION objective without explicitly setting creativeSelection, the behavior will default to OPTIMIZED starting with the July 2026 release and will apply to all versions."

How Should You Handle the Rotation Change in 2026?

Decide which behaviour you want and set it explicitly, rather than inheriting a default that changed underneath you. LinkedIn's guidance for keeping the old behaviour is direct: "To preserve even ad rotation, explicitly set creativeSelection as ROUND_ROBIN." It also notes that "OPTIMIZED is only valid for the SPONSORED_INMAILS type with the LEAD_GENERATION objective", and "all other objectives in this type still reject it with a 400 error."

  • If you are testing creative, set ROUND_ROBIN. Optimised rotation shifts delivery towards early winners, which undermines a fair comparison of message variants.
  • If you want delivery to favour performers, OPTIMIZED is now available for lead generation inbox campaigns, which it was not before.
  • If your tool creates campaigns, check whether it sets creativeSelection at all. If not, every lead generation inbox campaign it created since July runs optimised.
  • If you use another objective in this campaign type, do not send OPTIMIZED; it is still rejected.

What Does This Mean for B2B Lead Generation in 2026?

It means inbox formats need to be treated as changed channels, not continuing ones. Taken together, the two updates mean a lead generation Message Ad or Conversation Ad campaign running today behaves differently from the same campaign in May 2026, even with identical creative and budget. That matters most to B2B teams whose LinkedIn reporting rolls inbox results into blended cost per lead figures over long periods.

What Are the Common Mistakes in 2026?

  • Comparing inbox performance across June 2026 as if nothing changed.
  • Running creative tests on the new default. Optimised rotation is not a fair test.
  • Assuming the Not Interested button can be turned off. LinkedIn says it is not exposed in the API.
  • Skipping test sends. LinkedIn names them as the way to preview the behaviour.
  • Sending OPTIMIZED on non-lead-generation inbox campaigns. That still returns a 400 error.
  • Ignoring the new replyType value in integrations that parse Conversation Ad content.

LinkedIn Message Ads Changes in 2026: FAQs

What is the Not Interested CTA on LinkedIn Message Ads?

A call-to-action LinkedIn automatically renders on Message Ads and on the first message of Conversation Ads from June 2026. LinkedIn says it is applied to new and existing ads at render time and is not exposed in the API.

Can we turn off the Not Interested button?

LinkedIn's changelog says the CTA is not exposed in the API, so there is no API field to remove it. LinkedIn advises using test sends to preview the behaviour.

What changed about rotation for LinkedIn inbox lead gen campaigns?

From July 2026, SPONSORED_INMAILS campaigns with the LEAD_GENERATION objective default to OPTIMIZED creativeSelection on all versions when the field is not set. Previously that combination was rejected and forced to ROUND_ROBIN.

Does any of this show up in the API?
