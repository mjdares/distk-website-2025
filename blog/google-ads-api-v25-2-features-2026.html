Google Ads API v25.2 for Marketers in 2026: Benchmarks, PMax Drafts and Creator Insights

Minor API releases rarely deserve a marketer's attention. This one does, because it changes what your reporting can say about how an account compares with its competitors.

Distk Editorial Oct 2026 11 min read

Google Ads API v25.2 was announced on 23 September 2026 as a drop-in upgrade for v25, and Google's release notes state that minor versions like v25.2 contain no breaking changes. The marketer-relevant additions are competitive benchmark metrics in percentile tiers, which only populate when PERCENTILE_DATA is requested with the all-advertisers benchmark source and a category filter; creator insights searchable by YouTube channel handle; Performance Max drafts generated from existing Smart campaigns, created paused and incomplete; asset-group-level URL options for Performance Max; and Search recommendations that flag Target CPA or Target ROAS bids too tight to enter auctions. To use them you must upgrade client libraries and code. v25.2 is listed to sunset in August 2027.

What Is Google Ads API v25.2 in 2026?

Google Ads API v25.2 is a minor release announced on 23 September 2026, and Google describes it as "a drop-in upgrade for v25". The release notes state the rule that matters most for anyone deciding whether to upgrade: "Minor versions like v25.2 don't contain breaking changes." To use the new capabilities, Google says "you must upgrade your client libraries and client code", but nothing that already works on v25 should stop working.

For a marketing team, v25.2 is worth knowing for what it lets your reporting and tooling see. Two additions stand out: competitive benchmark data in percentile tiers, and creator insights searchable by YouTube channel handle. A third, generating Performance Max drafts from Smart campaigns, matters to anyone still running Smart campaigns for small-business clients. If your tools are still on v22, read our v22 sunset guide first, because v22 requests begin to fail on 7 October 2026 and v25.2 is a sensible target.

What Are Competitive Benchmark Percentiles, and Why Do They Matter in 2026?

They tell you where an account stands against other advertisers, expressed as a percentile tier rather than a raw average. Google's release notes say BenchmarksService.GenerateBenchmarksMetrics now provides "metrics representing the customer's competitive standing among other advertisers in percentile tier format", returned in PercentileMetrics on the new CustomerMetrics.percentile_metrics field and expressed using BenchmarksCustomerPercentileTier.

That changes a familiar agency conversation. "Your click-through rate is 3.1 percent" invites the question "is that good?" A percentile tier answers it against advertisers in the same category, from Google's own data, inside the account's reporting. For client reporting in 2026 it is one of the more useful additions Google has made to the API in a while.

The conditions that make percentile data appear

The field is not populated by default. Google states CustomerMetrics.percentile_metrics "is only populated when both of the following conditions are met":

  • PERCENTILE_DATA is requested in supplemental_data.
  • BenchmarksSource.all_advertisers is set on benchmarks_source, "which also requires specifying category_filter".

There is also a coverage caveat worth knowing before you build a dashboard. Customer aggregate, rate and percentile metrics are supported across all dates in supported_dates, including open quarters, but customer share metrics and the benchmark source's own rate metrics "are not supported for open quarters and are omitted from the response" unless the date range falls within the narrower supported_dates_for_all_metrics range. Google also added a BenchmarksError.NO_METRICS_FOUND error for input combinations that return nothing.

How Does Creator Search by YouTube Handle Help in 2026?

It removes a lookup step from creator discovery. ContentCreatorInsightsService.GenerateCreatorInsights now supports searching by YouTube channel handles through YouTubeChannels.youtube_channel_handles, in addition to channel IDs. Google notes that "valid channel handles must start with @, such as @channel_handle."

The practical gain is that influencer and partnership shortlists are written in handles, because that is how people refer to creators. Until v25.2, a tool had to resolve each handle to a channel ID before requesting insights. For teams running creator programmes alongside YouTube campaigns in 2026, that is one less brittle step in the pipeline.

What Does Generating a PMax Draft From a Smart Campaign Do in 2026?

It lets a tool convert an existing Smart campaign into a Performance Max draft programmatically. The new SmartCampaignSettingService.GeneratePMaxDraftCampaign method generates a draft that Google says is "initialized with a status of CampaignStatus.PAUSED and a creation status of CampaignCreationStatus.INCOMPLETE". Nothing goes live automatically, which is the right default for a conversion an agency should review.

  • Validate first: set GeneratePMaxDraftCampaignRequest.validate_only to true to receive warnings or conversion issues in validated_info without creating the draft.
  • What comes back: the response returns resource names for the generated pmax_campaign, campaign_budget, asset_group and assets.
  • Not yet supported: Google says to leave gbp_enabled and image_enabled unset or false, because setting them to true "is not yet supported" and returns an error.

For agencies managing many small local businesses, this is the most operationally useful item in the release, because migrating Smart campaigns one by one through the interface is slow.

How Should a Team Upgrade to v25.2 in 2026?

If you already run v25, the upgrade is low risk by Google's own description, because minor versions carry no breaking changes. If you are on an older major version, upgrade to v25 first using Google's version migration guide, which notes that "your endpoint will change when you change major versions", then take v25.2.

  1. Confirm which version your tools call, using the Google Cloud Console method described in our v22 guide.
  2. Update your client library to a release that supports v25.2. Google's changelog for each language lists the required version.
  3. Request PERCENTILE_DATA with the required benchmark source and category filter, and test on one account before rolling into client reports.
  4. For Smart campaign conversions, run validate_only first and review every draft before enabling it.
  5. Check whether any search campaigns are surfacing the new bid-too-low recommendations.

What Are the Common Mistakes in 2026?

  • Expecting new features without updating the client library. Google is explicit that you must upgrade client libraries and client code.
  • Building a benchmark dashboard without the required parameters. Percentile metrics only appear when PERCENTILE_DATA, the all-advertisers source and a category filter are all set.
  • Assuming share metrics cover open quarters. They are omitted outside the narrower supported range.
  • Setting gbp_enabled or image_enabled on PMax draft generation. Google says it is not yet supported.
  • Treating a generated draft as live. It is created paused and incomplete by design.
  • Jumping a major version straight into production. Major upgrades change the endpoint. Minor ones do not break, majors can.
